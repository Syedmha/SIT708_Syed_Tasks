# Lost and Found Map Mobile App

## Overview
The Lost and Found Map Mobile App is an Android application developed using Java and SQLite. The app allows users to create and manage lost and found item advertisements, store item details locally, and view item locations on Google Maps.

## Features
- Create Lost and Found item advertisements
- Store item details using SQLite database
- View all advertisements in a list
- Delete advertisements
- Search locations using Google Places Autocomplete
- Get current device location using GPS
- Display item locations on Google Maps
- Radius-based search for nearby items
- View item details through map markers

## Technologies Used
- Java
- Android Studio
- SQLite Database
- RecyclerView
- Google Maps SDK
- Google Places API
- Android Location Services


## Setup Instructions
1. Clone the repository.
2. Open the project in Android Studio.
3. Add your Google Maps API Key in the AndroidManifest.xml file.
4. Sync Gradle dependencies.
5. Run the application on an emulator or Android device.

## How to Use
1. Create a Lost or Found advertisement.
2. Enter a location using autocomplete or current location.
3. Save the advertisement.
4. View all advertisements from the home screen.
5. Open the map to view item locations.
6. Use radius search to find nearby items.
7. Delete items when required.
